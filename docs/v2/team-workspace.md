# V2 团队空间

团队空间集中展示共享会话、Skills、文档、共享指令、MCP、Env 和已接入的工作目录；各类资源有独立入口。团队连接与总开关位于「设置 → 团队」，默认关闭；本地页面保持原来的用途。

首次使用先看[连接与同步](#一次同步到所有工作目录)，日常操作看[共享空间与 Push](#共享空间与-push)，会话分享和恢复见[共享会话](#共享会话)。清单字段与安装规则见[团队资产参考](team-assets.md)。

## 共享空间与 Push

共享空间显示保存在这台电脑上的团队资源，包括尚未上传的内容。Skills 和文档通过「添加资源」选择工作目录中的文件；共享指令、MCP、Env 编辑后点击「保存到共享空间」。这些操作不会上传，重新打开应用后仍然保留。

Push 展示这份本地副本与上次同步的差异，只上传勾选项。Pull 获取远端更新并分发到启用的目录，保留未上传的本地内容。同一资源远端也有修改时，Push 会提示冲突；先查看 Diff，再编辑保存或重新添加核对后的资源。

会话或 Turn 选择目标团队后先保存本地副本，再打开上传清单。即使关闭上传窗口，也能在共享会话中阅读、搜索，在 Push 中继续上传。原会话之后的修改不会改变这个副本；需要新内容时重新加入。

## 一次同步到所有工作目录

1. 在设置连接 GitHub 团队资产仓库并启用团队。HTTPS/SSH 只在团队连接选项中设置一次，默认 HTTPS；输入 SSH 地址时自动选择 SSH。
2. 在团队空间的「工作目录」接入本地目录，选择 Codex、Claude Code 或两者。目录不必是 Git 仓库。
3. 点击团队顶部的「Pull 拉取」。应用拉取默认分支，然后安装或更新所有已启用目录中匹配客户端的团队 Skills、文档、共享指令、MCP 与公共环境变量。无需逐个安装、选择工作配置或在各页面重复设置连接方式。

Skills、文档、共享指令、MCP 和 Env 各自在独立页面展示团队发布的内容，点击后在右侧查看；窄窗口覆盖显示，关闭或按 Esc 返回原列表。团队仓库为空时页面明确显示尚未发布资源，接入本地目录不会自动把个人文件上传成团队资产。

连接目录或开启团队不会自动执行同步，更不会上传 Session。同步是一次明确的用户操作，不会执行 Skill 脚本、安装 Hook 或启动额外 MCP 服务。会话启动时的自动同步、用户全局安装、角色/逻辑项目筛选尚未实现。

## 按项 Push 与当前 Diff

团队页顶部提供两个方向明确的入口：**Pull 拉取**更新本地团队资源；**Push 推送**打开待上传清单。一个 Skill（含脚本和附件）、一份文档、一条配置或一个待分享 Turn 都是一项，默认不会把整个工作目录上传。

在 Skills 或文档页面点击「添加资源」，选择已启用工作目录中的条目，保存后即可在共享空间查看。 添加弹窗可按名称或路径筛选；筛选不会清除已勾选的条目，切换来源目录会清空选择。底部始终显示已选数量和确认按钮，一次最多添加 64 项。Push 清单只读取已保存的本地资源。点击条目，在右侧查看以上次 Pull 缓存版本为基准的本地 Diff，不会克隆远端仓库或准备上传包；读取期间仍可勾选和切换。已查看条目在本次窗口内复用，重新添加资源或保存编辑后，可刷新 Diff 重新核对。「查看所选 Diff」也只读取本地，实际 Push 前才核对远端并保留可上传快照。Diff 中：A 为新增，M 为修改，D 为包内文件删除；无变化项会显示一致并跳过。每个文件支持红绿逐行 Diff 和完整内容对照，长 Diff 限制显示前 800 行，完整内容和实际推送数据不截断。二进制文件保留原字节，预览显示大小和校验值。

勾选所需条目后可直接点击「Push 所选 N 项」，系统先准备快照再确认发布；也可先点击「查看所选 Diff」核对本次全部内容。资源变更在同一个提交中发布，保留未选资源与仓库其他文件；Turn 使用独立的不可变分享快照，可切换为本地会话同款阅读视图。分享不会合并或覆盖历史会话。上传完成后成功项移出清单，失败或取消项保留，按项显示结果；请求结果未确认时应先核对远端再重试。

预览保存当时的文件副本并绑定当前窗口、团队和远端版本，有效期十分钟。预览后修改原始文件不会改变已保存的工作副本；需要重新加入资源，再预览新内容。远端在预览期间发生变化时停止推送，先 Pull 后重试。Push 不会自动 Pull 或更新本地工作目录。

每次最多选择 64 项；单个 Skill 最多 200 个文件，选中 Skill 的完整文件总量或一份文档最多 1 MiB，资源变更完整输入和预览最多 4 MiB，混合资源与轮次的完整 Diff 回复最多 16 MiB。链接、环境文件及 Git 元数据不进入 Skill 推送，安装归属标记不上传。更新 Skill 时可删除其包内文件，但本地缺少某个 Skill/文档不会自动删除整个团队资源。配置、资源和待分享轮次保存在本地，关闭应用后仍能查看和继续上传。

## 在 App 中新增与编辑资源

先同步一次团队，随后在「共享指令」「MCP」「Env」页面点击「新增」。打开已有条目的详情后，可点击「编辑」。标识自动生成，创建时可调整；编辑保留原标识或变量名。

- 共享指令：填写名称、Markdown 正文和适用客户端。新增指令使用独立文件，已有指令保留原文件位置。
- MCP：填写名称、HTTP 地址或 STDIO 命令和参数；请求头、服务器环境变量可选择共享值或本机变量引用。引用只保存变量名，不读取本机的实际值。
- Env：填写变量名、公开共享值和适用客户端；内容会进入团队 Git 仓库，不适合填写密钥。

点击「保存到共享空间」，立即在对应页面查看本地内容，Push 清单同时出现其差异。勾选条目并查看 Diff 后，点击「Push 所选项」并完成系统确认。预览归当前窗口所有，有效期十分钟。发布写入团队仓库默认分支的新提交，保留其他文件，并将已上传项移出变更清单；之后点击「Pull 拉取」才会更新工作目录。发布不会启动 MCP，也不会自动上传个人配置或会话。

需要现有 Git 凭据具有写权限；分支保护要求 PR 时，仍需通过仓库审核流程发布。仓库在编辑期间发生变化会停止发布，先同步后重新编辑/预览，不强制覆盖其他成员的提交。已有版本 1—3 清单在发布新类型资源时显式升级到版本 4；旧客户端需升级。这三类配置可在桌面编辑；Skills 和普通文档通过 Push 清单从已接入目录中选择。贡献 PR 流程仍由仓库维护。

若提示「发布结果尚未确认」，先同步核对远端，避免重复提交。推送已成功但缓存或临时文件保存失败时，会明确提示资源已经发布；可通过同步恢复列表，检查配置目录权限以清理临时文件。默认暂存目录为 `~/.agentrecall-cli/configuration-edits`；使用 `AGENTRECALL_HOME` 时位于相应配置目录内。单份指令最多 1 MiB，完整清单最多 1 MiB，完整变更预览连同元数据最多 4 MiB，超限明确拒绝。

## 自定义资源文件夹

团队 Skills、文档、共享指令、MCP 和 Env 页面可切换“全部”“未分类”及自建目录。点击“新建文件夹”，输入如“前端”；进入后可建立“前端/代码审查”子目录。选择目录后可重命名或移动路径，也可确认删除该目录及子目录，原资源移回未分类。

勾选多项后点击“移动所选”，或右键单项选择目标目录。添加本地 Skill、文档时可以选择已建目录。分类先保存在本地共享空间，通过 Push 查看差异并发布，其他成员 Pull 后获得目录结构。资源加载和安装位置不随分类改变。

## 同步写到哪里

| 资源 | 接入目录内的目标 |
| --- | --- |
| Codex Skills | `.agents/skills/<id>/` |
| Claude Code Skills | `.claude/skills/<id>/` |
| `AGENTS.md` | 开启 Codex 时同步到根目录 |
| `CLAUDE.md` | 开启 Claude Code 时同步到根目录 |
| `docs/*.md` | 按清单 target 同步到相应文档路径，一份目录只写一次 |
| 共享指令 | Codex 的 `AGENTS.md`、Claude Code 的 `CLAUDE.md` 团队区块 |
| Codex MCP / Env | `.codex/config.toml` 的受管区块 |
| Claude Code MCP | `.mcp.json` 的团队服务器条目 |
| Claude Code Env | `.claude/settings.json` 的团队 `env` 键 |

共享指令由客户端读取。Codex 只在信任的目录中加载项目配置，Claude Code 可能要求确认项目 MCP；已有客户端会话可能需要重启。同步完成表示文件已经写入，不代表服务器启动、凭据可用或工具连接成功。

Markdown 与 TOML 保留受管区块之外的原始文字；JSON 保留个人字段和值，重新格式化输出。同名个人 MCP/Env、受管条目本地修改、删除、符号链接、硬链接或损坏记录均停止该文件写入。Codex 已有 `shell_environment_policy.set` 表时，本版保留整个文件并报告需要手动合并，不覆盖个人变量。一个配置文件内的变更作为一组，其他文件和目录可以继续同步。

版本 4 清单移除配置时，只撤回未修改的团队区块或条目。禁用某客户端不会删除其配置。整个配置文件最多 1 MiB；归属记录 `.agentrecall-configuration.json`（版本 1）也以完整序列化值计算 1 MiB 上限，未知版本明确拒绝。旧文件备份到 `.agentrecall-configuration-backups`，更新记录失败尝试恢复文件；意外中断导致归属不一致时保留现场并报冲突，可检查备份后恢复，不自动认领未知内容。


分发后的技能由客户端自己的发现和加载机制使用。普通文档仅落盘，不代表 Agent 会自动阅读；检索指引和自动召回属于后续能力。

## 冲突、失败与备份

- 本工具已管理且未修改的副本自动更新，旧 Skill 和文档先移入备份。
- 同名个人内容、本地修改、其他团队来源、链接或损坏记录不会被覆盖。即使个人文档与团队正文相同，也不自动接管后续更新权限。
- 团队清单删除的受管副本，在确认没有本地修改后移入备份。某类资源出现更新冲突时，其待退役旧副本暂时保留，避免新内容未落地而旧内容先消失。
- 关闭一个客户端或停用/断开目录会保留已有文件；停用目录不参与后续同步。断开需系统确认。
- 目录之间独立处理，单项失败不伪装为整轮成功。页面显示「部分内容未同步」并列出具体目录、资源、原因和备份。取消保留已经完成的变更，尚未处理的目录标记取消。
- 文档文件和归属记录更新失败时尝试恢复原文件；无法恢复时明确报告需要处理，保留现存文件和备份。重试重新核对实际状态，不强制覆盖。

Skill 备份位于 `.agentrecall-skill-backups`，文档备份位于 `.agentrecall-document-backups`。文档归属记录为 `.agentrecall-documents.json`（版本 1），未知版本或损坏时停止该目录的自动写入。此前逐项应用且没有归属记录的文档不自动认领；遇到不同内容需先手动检查、备份和合并。

旧工作配置仍保护它引用的 Skill。整轮同步不会绕过这些引用；如遇 `SKILL_IN_USE`，先使用 CLI 的 work-config 更新或卸载相关配置再重试。新版页面不要求安装工作配置，清单中的分组定义不会被自动安装成额外副本。

一次同步最多处理 32 个连接目录；每目录的目标与候选退役条目最多 511 项，另保留一项目录级失败报告。同步结果完整 JSON 最多 16 MiB，保存最近一次结果供重新打开页面查看；历史结果不代表后来更改的目录配置已经同步。包含共享配置的新版报告使用格式版本 2，仍读取版本 1 报告；旧客户端不支持版本 2，需升级后查看。

## 配置兼容

旧配置版本 1/2 的仓库项目只读投影为目录连接，版本 3 保存目录连接。版本 4 增加每团队的连接方式；首次保存连接方式时升级，并保留旧 projects、连接列表、安装记录和分享。不支持新版本的旧客户端明确拒绝，需同时升级 CLI 与桌面。

旧逻辑项目不再作为桌面导航层级。同一团队仓库内的旧项目会话汇总到团队列表，包和远端对象不搬迁、不删除。

## 共享会话

本地 Session 右键 →「上传到团队…」→ 在当前页面的弹窗中选择团队 → 点击「上传所选 N 项」→ 确认上传。只有一个团队时直接展示本次上传内容；多个团队时先在弹窗选择目标。不跳转团队页面，也不必另外打开 Push。窗口仅选中本次发起的会话或轮次，关闭后仍可在团队 Push 中找回待上传项。

「查看所选 Diff」是可选操作。直接上传也会先打包、校验并冻结内容，再由主进程确认发布；准备失败时显示原因，不继续上传。完整会话的 Diff 显示范围、压缩大小、文件及缺失附件清单，不把整条会话展开成巨大文本。预览十分钟后过期，切换目标需重新预览。资产同步不会上传任何会话。

也可以在会话详情中右键某个 Turn →「多选轮次…」，勾选需要的轮次，再点击「分享到团队…」，每个 Turn 会成为独立待上传项。同样在当前页面打开上传窗口，选择目标团队后直接上传，也可以先查看 Diff 或会话视图。右键的轮次会自动选中；滚动不会丢失勾选，切换会话或取消多选会清空选择。多选入口一次可加入 1–500 个轮次；Push 每次最多处理 64 项资源，其中最多 8 个会话或轮次片段。每个所选 Turn 保存为独立片段，未勾选轮次不上传；清空后不能提交。

轮次片段保留所选轮次的消息、工具输入/输出与关联、轮次标识和可读取附件，以及来源会话的标题、标识和来源类型。不包含整份原始会话文件、未选轮次、子会话、会话总摘要或本地工作目录。所选消息与工具记录仍可能包含敏感内容，不自动脱敏。预览与团队阅读页明确标注「会话片段」，并保留原轮次序号，直接复用本地会话的 Turn 阅读组件，支持 Markdown 消息与工具调用展开；附件随分享包下载查看。后台重新核对轮次归属，已不存在的轮次直接报错，不会退回整条会话分享；附件按标识去重，最多 512 个。此功能仅在 V2 提供：V1 没有团队空间和轮次分享入口。

完整会话包保存主会话、已索引的子会话、对话、工具事件、原始源文件及可读取附件，不自动脱敏。缺失附件逐项列出；上传前需核对内容。成员可阅读、下载，作者或仓库管理员可撤回。已下载到外部设备的副本无法远程收回。

完整会话与轮次片段都支持公开和私有 GitHub 团队仓库，使用 Release 附件，标签 `agentrecall-sessions-v1`，不进入 Git 提交历史、不设为 Latest。需要本机 `gh auth login` 及仓库 Contents 权限，分享/撤回需写权限。公开仓库中的分享可被任何人访问和下载；私有仓库按仓库权限访问。预览和上传确认会说明这一点，不因仓库公开而阻止分享。上传前仍核对写权限；管理员改变仓库可见性会改变附件可见范围。

新分享采用版本 4 分块清单：长文本、内嵌图片和文件的 base64 内容无损分离，按内容去重，再以最多 4 MiB 的原始块分别 gzip 压缩。内容块存放在独立的 `agentrecall-session-blocks-v1` Release，不混入会话列表。相同内容可复用已有块；上传完成全部块后才发布分享记录，缺块或校验失败不会显示为完整会话。下载会重新组装为可独立保存的 `.agentrecall-session.json.gz` 文件。仍读取版本 1/2（完整会话）和 3（轮次片段），新清单需要新版客户端读取。

每次分享有独立记录；列表中的上传人来自 GitHub 返回的实际账号。两个成员上传相同内容可以复用块，但各自保留分享记录和撤回权限。来源 Agent 与会话标识随清单保留，它们是上传内容声明，不是原始创作者的身份证明。撤回删除分享记录，不删除其他分享可能使用的内容块；当前没有孤立块清理，撤回不等于从远端清除内容。

阅读版本 4 会话时，只还原正文及文件信息，跳过单独编码的原文件和附件数据块；这些文件在下载完整包时才读取并校验。所需块最多四路并行读取，同一次阅读中每个块只下载和解压一次，已上传的版本 4 分享不需要重新上传。点击 Pull 后，应用逐条将缺失会话的消息和工具事件保存到本地。之后打开同一分享直接读取本地数据，刷新页面、切换团队和重启应用后仍可复用。阅读与本地会话使用相同的轮次组件，每页显示 50 轮，展开时再读取该轮正文。首次 Pull 和整理需要等待。旧版本的单 gzip 包首次仍需完整下载。

当前仍使用内存快照准备，首次导入时一次还原阅读所需的消息和工具记录。包及解压后的完整 JSON 各最多 64 MiB，单源文件/附件最多 16 MiB，最多 128 个会话。完整快照仅支持源文件可读的本地会话，子会话范围来自索引。轮次分享支持本机已索引的轮次。因此目前不能完整上传 500 MB 源会话，应先选择需要的轮次。上传失败后重新准备可复用已成功上传且校验一致的块，本地待上传副本可跨重启保留，但自动恢复进行中的网络上传与流式打包尚未提供。CLI 会话分享、搜索筛选与导入恢复也尚未提供。

## 维护和验证边界

团队资源通过 Git 仓库清单发布，格式见[团队资产指南](team-assets.md)，CLI 命令见[CLI 指南](cli.md)。个人新增/修改资源的贡献 PR 界面尚未实现，不以“同步”为名自动发布个人内容。

测试使用临时目录、合成仓库与模拟 GitHub 接口；界面使用真实组件和合成数据检查。未向真实仓库上传个人会话，也未替用户在真实工作目录执行批量同步。真实仓库两名成员的完整联调仍待验收。


共享会话采用与本地 Session 一致的列表与阅读分栏，可调整列表宽度。Pull 同步会话列表并依次准备尚未保存的会话，完成后可离线阅读与搜索。页面打开、列表刷新、搜索、展开轮次都不会联网。准备未完成时提示点击上方 Pull；失败或取消会保留已完成副本，再次 Pull 重试。同步期间每次处理一条会话，避免多份大包同时占用内存。

团队资源导航与 Pull、Push 操作位于同一工具栏；最近同步结果可展开查看，共享会话区填满剩余空间。会话标题不再重复显示于搜索栏上方。

共享会话上传时同时发布来源 Agent，列表与阅读标题可直接显示 Codex、Claude Code 等来源，无需先下载正文。旧分享未发布来源时，优先使用已下载副本的本地索引补充；没有依据时保留未知状态，不根据标题猜测。

搜索与普通 Session 页使用同一输入组件：输入后按 Enter 搜索，支持最近搜索，清空输入恢复列表。一次匹配标题、分享者、对话内容及工具名称；需要查日志时勾选「搜索包含工具输出」。完整会话和单独分享的 Turn 都可搜索，每份分享只显示一次；正文命中时点击结果定位并展开对应轮次。搜索覆盖当前团队全部已索引会话，不局限于当前列表页。升级后先执行一次 Pull 建立本地目录，之后重启也能离线查看。阅读本身不执行 Resume；需要继续工作时使用「导出为 Session」。

「搜索包含工具输出」是搜索范围复选项，不控制阅读区的显示。没有关键词时切换只保留选择，不刷新列表或关闭当前会话；已有关键词时按新范围重新搜索。

共享会话阅读区提供「导出 MD」和「导出 JSON」，完整会话与 Turn 片段均从本地索引分页导出，不访问远端。导出包含该分享的全部会话记录与轮次，不受当前搜索或分页限制。JSON 标记为 `agentrecall-shared-session-export` 版本 1，保留片段标记、Agent 来源、轮次、消息和工具记录；MD 用于阅读。两者不包含原始会话文件或附件文件，不是可 Resume 的原始会话包。导出上限为完整输出 64 MiB；本地内容未准备完成时要求先 Pull，取消保存不报告成功。

「导出为 Session」按原 Agent 创建新的本机会话；选择本地工作目录后，写入对应客户端的原生会话目录并加入普通 Session 列表，可在那里 Resume。支持现有迁移写入器支持的 Agent，未知来源拒绝恢复。完整分享与 Turn 片段均只用本地已索引内容：片段只恢复已分享轮次，工具记录转换为历史上下文文本，子会话以带标题的历史文本合入新会话，附件仅保留名称，不恢复文件、不重放工具、不自动启动 Agent。每次创建新的会话 ID，不覆盖原会话。索引失败会报告文件已创建，刷新列表即可，无需重复导出。
