# V2 团队空间

V2 在主导航提供独立的「团队空间」。本地 Session、Skills 等页面保持原有布局；团队连接与总开关在「设置 → 团队」。团队功能默认关闭，开启、连接或同步资产都不会自动分享会话。

## 团队与项目

1. 在设置中连接一个 GitHub 团队资产仓库并开启团队功能。
2. 进入「团队空间」，选择团队，在团队内创建项目并关联本地 Git 目录。名称可选，远端可在高级选项中指定。
3. 打开项目后，在「共享会话 / Skills / 文档」之间切换。没有团队 Memory 或工具配置入口。

每个团队只显示自己的项目。首版项目仍需本地 Git 目录；Skills 和文档共用团队资产库，分别应用到各项目，并未实现项目专属的资产分区。共享会话以业务 GitHub 仓库的规范地址识别项目，成员的本地目录可以不同；fork 是另一个项目。没有 GitHub 远端的项目仍可使用 Skills 与文档。

配置与 CLI 共用，见 [CLI 指南](cli.md)。旧的默认团队继承保持兼容；新增桌面项目明确归属当前团队。未归属团队的已有项目可关联到团队，移除绑定须确认且保留代码、安装和备份。CLI 改动后手动刷新，暂无自动监听。

## 共享会话

在本地 Session 列表中右键 →「分享到团队…」→ 选择团队项目 →「预览完整会话」→ 检查内容 →「确认分享…」。主进程还会显示系统确认框。预览只在本机生成，十分钟后过期；切换目标需重新预览。

会话包包含主会话、已索引的关联子会话、对话、工具事件、元数据、可读取的原始源文件和附件。不会自动脱敏，原始内容中可能有本地路径和敏感文本，分享前需自行核对。不可读取的附件会逐项列出，并在确认框中显示数量；不将缺失附件伪装成完整附件。

从团队项目可阅读消息、子会话和工具事件，下载完整 `.agentrecall-session.json.gz` 包；作者或仓库管理员可撤回。撤回只删除远端附件，本地原会话及成员已经下载的副本保留。首版不提供把下载包导入本地索引或恢复到原 Agent 的操作。

### 存储和权限

完整会话保存在**私有团队资产仓库**的 GitHub Release 附件中，不进入 Git 提交历史。受管预发布标签为 `agentrecall-sessions-v1`，不会标为 Latest。Skills 和文档仍使用 Git 同步，公开资产仓库可以正常使用这两类内容。

会话访问使用本机 GitHub CLI：需安装 `gh`，完成 `gh auth login`，并拥有仓库 Contents 读取权限；分享和撤回还需要写入权限。桌面不保存该令牌，也不传给界面或附件的签名下载地址。只有 SSH 克隆权限而没有 GitHub CLI 登录，不足以操作会话附件。权限由 GitHub 仓库成员管理，本应用暂不管理邀请与成员角色。

每次操作检查仓库仍为私有；公开仓库拒绝上传完整会话，不自动更改可见性或创建另一个仓库。仓库管理员以后若将仓库改为公开，GitHub 上已有附件也可能随之公开；应用检查不能替代仓库权限管理。

上传收到不确定结果时保留预览，重试会验证并复用同一内容的附件。重新生成预览会生成新的快照。超过每仓库 10,000 个附件的读取范围需先整理存储；当前列表每页读取 100 个仓库附件，再筛选当前项目，故可能存在空页。

### 大小与来源限制

- 完整 JSON（含 Base64 文件、元数据和包装）最多 64 MiB，压缩包也最多 64 MiB；超限失败，不截断。
- 单个源文件或附件最多 16 MiB，最多 128 个主/子会话，每会话最多 512 个文件、100,000 条消息与 100,000 条工具事件。
- 只分享本地、源文件可读的会话。远程或仅缓存的会话不支持；SQLite 来源也受源文件大小限制。会话索引达到 100,000 条时拒绝生成，避免遗漏子会话。
- 子会话范围来自当前已索引关系；未索引会话无法自动发现。页面分页和逐步展开只影响显示，包内数据不截短。

## Skills

选择客户端和 HTTPS/SSH 连接方式，手动同步后预览、安装。Skill 和工作配置沿用已有版本、归属与备份规则，详见 [团队资产指南](team-assets.md)。关闭团队后仍可进入项目的 Skills 管理已有本地工作配置，关闭不卸载任何内容。

## 文档

支持清单声明的 `AGENTS.md`、`CLAUDE.md` 以及 `docs/` 下 Markdown。手动同步后选择文档，查看团队版本、提交号、目标位置和本地内容，再应用到所选项目。

首版仅创建缺失文件，内容相同则保留；有不同内容时拒绝覆盖，需用户在编辑器中合并。来源、版本或项目绑定改变也会拒绝旧预览。链接、非法路径和非 UTF-8 文件均不会写入。文档暂不支持应用内编辑、自动合并、提交 PR 或版本回滚。发布方法和格式见[文档清单](team-assets.md#文档清单)。

## 验证边界

共享读写、权限、哈希校验、取消和文档写入使用合成数据与模拟 GitHub 接口验证。受控浏览器检查真实 React 组件，但不代表真实私有仓库权限或原生 Electron 完整联调验收。没有为了测试上传个人会话；真实私有仓库端到端验收仍待进行。
