# V2 资源目录：找全、看清，不在页面里编辑

## 文档状态

- 状态：分阶段实施中。阶段 A（通用目录布局、侧栏收窄、「指令」页只读查找）已实现，见 [指令规格](../spec/instructions.md)。
- 适用范围：`apps/main-2.0`。V1 不做。
- 关联：决策见 [ADR 0026](../adr/0026-v2-resource-catalogs.md)；调整 [资源与范围设计](2026-11-22-v2-resources-and-scopes-design.md) 中资源页可编辑、个人与团队互相复制的部分；视觉规范沿用 [界面重做设计](2026-11-22-v2-ui-redesign-design.md)。

## 要解决的问题

- 资源页留了大块的编辑空间（例如指令页的大编辑框和每个 Agent 的开关），但指令、Skill 大多由 Agent 写，人需要的是知道有哪些、在哪里、内容是什么。
- 页面布局不一致：有的页面内容居中限宽 760 px，有的铺满，有的混用，切换页面时位置跳动，宽屏左侧大片空白。
- 侧栏 180 px 偏宽。

## 原则

1. **找全**：每个资源页列出本机所有 Agent 用户级、有会话的项目里、以及团队里的同类内容，按来源分组，同一份内容只列一次并标出所有来源。
2. **看清**：选中后在右侧看到完整内容和关键信息（路径、来源、大小、修改时间）。
3. **不在页面里编辑**：本机文件用系统默认编辑器打开或在文件夹中显示；团队内容去团队空间编辑。只保留确实需要在 AgentRecall 里完成的操作（如安装 Skill、删除经验卡、Gateway 工具源）。

## 通用布局

- 顶部一行：标题、数量、搜索框、操作按钮。
- 下面全宽分成两栏：左侧可拖动宽度的分组列表，右侧详情；窄窗口时上下堆叠。
- 组件：`CatalogPage`、`CatalogSearch`、`CatalogGroup`、`CatalogItem`、`CatalogDetail`（[catalog.tsx](../../apps/main-2.0/src/renderer/src/ui/catalog.tsx)），样式 `styles/catalog.css`。
- 侧栏宽度 150 px。

## 各页面

| 页面 | 列表 | 详情 | 保留的操作 |
| --- | --- | --- | --- |
| 指令 | Agent 用户级、每个项目、每个团队 | 正文预览 | 用编辑器打开、在文件夹中显示；团队条目去团队空间编辑 |
| Memory | 按项目分组的经验卡 | 问题、做法、无效做法、来源轮次 | 删除、打开来源会话、提升为 Skill；提炼设置放在顶部 |
| Skills | 一个去重列表，标出出现在哪些 Agent、Skill 库、团队 | SKILL.md 预览与文件 | 安装到 Agent、加入 Skill 库、打开文件夹 |
| MCP | Gateway 工具源、各 Agent 与项目配置里的服务器、团队 MCP | 命令或地址、变量名、工具 | Gateway 工具源的测试与开关 |
| Provider 等其余页面 | 改为同样的全宽布局 | — | 不变 |
