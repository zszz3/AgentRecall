# AgentRecall 1.0 使用指南

[返回项目首页](../../README.md)

AgentRecall 集中管理 Claude Code、Codex 等 AI Coding Agent 的历史会话。你可以搜索过去的对话、查看完整上下文、整理重要记录，也可以继续或迁移会话。

![AgentRecall 主界面](../../assets/show.png)

## 1. AgentRecall 能做什么

AgentRecall 默认只启用 Claude Code 和 Codex。CodeBuddy、CodeWiz、TClaude、TCodex、OpenClaw、Hermes、OpenCode、ZCode、Cursor Agent、Trae、Qoder 都需要在 **设置 → 可选来源** 中手动开启。

| 类型 | 包含的来源 |
| --- | --- |
| 默认来源 | Claude Code CLI、Claude Desktop、Codex CLI、Codex Desktop |
| 可选来源 | CodeBuddy、CodeWiz、TClaude、TCodex、OpenClaw、Hermes、OpenCode、ZCode、Cursor Agent、Trae、Qoder |
| 扩展环境 | SSH 远程环境、Windows WSL |

打开应用后，已有会话会出现在主界面。左侧按环境、项目、来源、收藏和隐藏状态浏览，顶部用于搜索和打开各项功能。

各来源支持的功能不完全相同。打开会话后，界面只会提供当前可用的 Resume、迁移、同步、删除和导出操作。某项操作没有显示，通常表示当前来源或环境不支持。

## 2. 安装与首次使用

AgentRecall 支持 macOS 和 Windows，需要 Node.js 22.13 或更高版本。安装最新版本：

```bash
npm install -g https://github.com/zszz3/AgentRecall/releases/latest/download/agent-recall.tgz
agent-recall
```

应用启动后会常驻菜单栏或系统托盘。macOS 默认使用 `Option + Space` 打开搜索窗口，Windows 默认使用 `Ctrl + Alt + Space`。快捷键冲突时，可以在 **设置 → 全局快捷键** 中修改或关闭。

首次打开时，等待会话加载完成。如果刚结束的会话没有出现，点击左侧的 **更新索引**。需要使用其他 Agent 时，进入 **设置 → 可选来源** 开启对应来源，再更新一次索引。

macOS 用户还可以执行 `agent-recall install-app`，之后从 Launchpad、Spotlight 或 Dock 直接启动。安装、更新、回滚和卸载说明见 [Install.md](../../Install.md)。

检查或安装更新：

```bash
agent-recall --check-update
agent-recall --update
```

应用内也可以进入 **设置 → 关于** 检查更新。日常使用不需要重新安装依赖，直接运行 `agent-recall` 即可。

## 3. 搜索、查看和整理会话

### 搜索会话

在主界面按 `Cmd+F`（macOS）或 `Ctrl+F`（Windows）聚焦搜索框，输入关键词后按 Enter。搜索结果会显示命中的会话标题、项目或消息片段，点击片段可以直接打开对应位置。

结果较多时，按以下条件缩小范围：

- 左侧选择环境、项目、标签、来源，或只看收藏和隐藏会话。
- 顶部切换会话状态、时间范围，以及智能、最新、最早排序。
- 在 **高级搜索**中组合来源、标签、时间和可见性条件。
- 把常用条件保存为 **保存的搜索**，下次可以直接复用。
- 切换分组方式，按项目、来源或其他条件浏览结果。

搜索框会保留最近使用的关键词。可以从下拉列表重新执行，也可以逐条删除或全部清空。

### 查看会话

点击结果打开会话详情。详情页显示完整对话、Markdown、代码块、工具事件和附件。使用顶部的 **全部 / 用户 / 助手** 切换消息范围；不想查看工具事件时，可以在详情页关闭对应显示。

图片和文本附件可以直接预览。PDF 和其他文件可以交给系统应用打开。附件来自会话内容，打开不熟悉的文件前请先确认来源。

详情页中按 `Cmd+F` 或 `Ctrl+F` 查找当前会话。Enter 跳到下一个匹配项，Shift+Enter 返回上一个，Esc 关闭查找栏。

### 整理会话

- 点击标题旁的编辑按钮重命名会话。
- 点击星标加入或取消收藏。
- 在详情页使用 **添加标签**；点击已有标签可以移除。
- 右键会话可以重命名、添加标签、收藏、隐藏，也可以使用 Resume、迁移和导出等操作。
- 左侧的 **收藏**和**隐藏**入口用于集中查看对应会话。
- 删除操作只会在当前来源支持时出现。确认前先看清提示中的删除范围。

## 4. 继续、迁移和导出会话

### 继续会话

支持 Resume 的会话会在详情页显示 **Resume** 或 **在 Codex 中打开**。点击后，AgentRecall 会使用设置中的默认终端打开原会话。选中搜索结果后，也可以按 `Cmd+Enter` 或 `Ctrl+Enter` 快速继续。

需要手动执行时，点击 **复制命令**，再把 Resume 命令粘贴到终端。

SSH 和 WSL 会话的 Resume 会在对应远程环境中执行。连接不可用或目标 CLI 没有安装时，先到 **设置 → 连接** 运行检查。

### 迁移会话

点击 **迁移到…**，选择 Claude Code、Codex、CodeBuddy、CodeWiz、Cursor Agent、TClaude 或 TCodex。迁移完成后会打开新的目标会话；如果自动打开失败，界面会给出可复制的恢复命令。

迁移到 CodeBuddy、CodeWiz、Cursor Agent、TClaude 或 TCodex 前，需要先在 **设置 → 可选来源** 中开启对应 Agent。某个来源或环境不支持迁移时，迁移入口会隐藏或不可用。

### 导出会话

详情页提供以下操作：

- 复制 Markdown。
- 导出 Markdown 文件。
- 复制纯文本。
- 导出 JSON。

导出 JSON 时可以选择 OpenAI Chat、OpenAI Responses 或 Anthropic 请求格式，便于保存或交给其他工具继续处理。导出的请求可能包含完整提示词、工具参数和模型回复，请保存在可信目录中。

## 5. AI 摘要与自然语言找会话

打开会话详情后，点击 **AI 摘要**生成摘要；已有摘要的会话可以重新生成。摘要会显示在详情页，也能被普通搜索和 AI 找会话使用。

点击顶部的 **AI 找会话**，直接描述想找的内容，例如“上次处理 SQLite 迁移问题的会话”。结果卡片会显示匹配的标题、来源、项目和摘要，点击即可打开。

首次使用前，点击顶部的钥匙图标打开 Provider：

- 使用当前 Codex 配置。
- 使用当前 Claude Code 配置。
- 填写自定义的 OpenAI-compatible 接口、模型和 API Key。

AI 摘要和 AI 找会话会把相关会话内容发送给所选 Provider。API Key 只保存在本机；仍需根据自己的隐私要求选择服务和发送内容。

## 6. 远程会话

远程会话用于查看其他开发环境中的 Agent 会话。

### SSH 环境

进入 **设置 → 连接**，添加 SSH 主机并完成连接检查。刷新后，远程项目和会话会出现在左侧环境列表中，可以沿用主界面的搜索、筛选和详情查看功能。来源支持 Resume 时，也可以从详情页继续远程会话。

SSH 环境可以单独设置主机、端口、用户名和认证方式。保存前先运行连接测试；连接成功后再更新索引。远端来源和本地来源一样，只有支持的操作才会显示。

### Windows WSL

Windows 用户可以在 **设置 → 连接** 中添加已安装的 WSL 发行版。添加后，WSL 中的 Claude Code 和 Codex 会话会显示在环境列表中，并支持搜索、查看和 Resume。

WSL 会话目前不支持迁移。如果远程会话没有更新，可以在连接设置中刷新或运行诊断，再点击主界面的 **更新索引**。

## 7. 跨设备同步

会话同步使用你自己的 Supabase 项目。进入 **设置 → 远程同步**，填写 Project URL 和 anon key，按页面提示复制并执行初始化 SQL，然后启用远程同步。

点击顶部的云朵图标打开 **会话同步**：

- 上传单个或多个本地会话。
- 搜索和查看云端会话。
- 按来源筛选云端会话。
- 查看本地与云端的同步状态。
- 把云端会话恢复到当前设备，并选择目标 Agent 和项目目录。
- 删除云端副本；本地会话会继续保留。

同步窗口会显示以下常见状态：

- **仅本地**：还没有上传。
- **待更新云端**：本地内容比云端新。
- **已同步**：两边内容一致。
- **云端较新**：云端有更新版本。
- **仅云端**：当前设备没有本地副本。
- **内容冲突**：本地和云端都发生了变化，需要手动选择。

批量上传会跳过冲突，不会静默覆盖云端内容。恢复会创建新的本地副本，删除云端副本也不会删除原会话。

需要自动同步时，可以在远程同步设置中安装 Claude Code 和 Codex Hooks。Hooks 会记录待同步会话，由后台应用更新云端；应用没有运行时，会在下次启动后继续处理。只想偶尔备份时，直接在详情页使用 **保存到远程**，或在会话同步窗口手动上传即可。

附件同步可以在远程同步设置中开关。关闭后不会上传新的附件，会话正文仍可同步。

## 8. Skills 管理

点击顶部的包裹图标打开 **Skills 管理**。这里会集中显示 Codex、Claude Code 和 Qoder 的用户或项目 Skills。

Skills 面板支持：

- 按名称搜索，按来源筛选，并按名称或使用次数排序。
- 预览 `SKILL.md`，复制路径或在文件管理器中打开目录。
- 刷新使用统计。
- 删除非系统 Skill。
- 选择符合条件的本地 Skill 上传。
- 在另一台设备安装、更新或批量下载云端 Skill。
- 查看云端版本并恢复指定版本。

跨设备同步需要在 **设置 → Skills** 中配置 Supabase。可以复用会话同步使用的同一个 Supabase 项目。

本地列表会标记未上传、已同步、本地较新、云端较新或冲突。系统 Skill、项目 Skill 和由插件管理的 Skill 可能不会提供上传入口；这类内容通常由系统、Git 或插件本身管理。

## 9. Rules 与 Memories

点击顶部的数据库图标打开 **数字资产**。

**Rules 规则**用于查看和同步 Claude Code 的 `CLAUDE.md`、Codex 的 `AGENTS.md` 以及 Qoder Rules。**Memories 记忆**用于查看和同步 Qoder、Codex 的长期记忆。

两个页面都会显示本地、远端内容和同步状态，并提供全部上传、单项上传和远端删除。Rules 还可以把远端规则还原到本机。删除远端内容不会自动删除本地文件。

使用前，在 **设置 → Skills** 中启用 Rules 或 Memories 同步，并完成页面提示的 Supabase 配置。它们可以复用 Skills 的同步配置。

## 10. MCP 集成

MCP 让 Claude Code、Codex、CodeBuddy 等 Agent 在对话中直接使用 AgentRecall。进入 **设置 → AI**，打开 **启用会话检索 MCP**，然后重启对应 Agent。

启用后，可以让 Agent：

- 按关键词、来源或项目搜索历史会话。
- 读取某个会话的内容。
- 查看最近会话、项目和标签。
- 添加标签、收藏或隐藏会话。
- 把本地会话迁移到其他 Agent。

例如，可以直接说“找出上次修复登录超时的会话”或“把最近的 Codex 会话迁移到 Claude Code”。

MCP 中执行迁移时会返回 Resume 命令，不会替你自动操作终端。检查目标 Agent 和项目目录后，再运行返回的命令。

## 11. Provider、用量与设置

点击顶部的钥匙图标打开 Provider。这里分别管理：

- Codex 使用官方账号还是自定义接口。
- Claude Code 使用官方账号还是自定义接口。
- AI 摘要与 AI 找会话使用哪个来源和模型。

修改 Codex 或 Claude Code 的运行配置前，先确认目标 Provider、模型和 API 格式。只想改变 AgentRecall 的摘要来源时，使用 **AI 摘要与搜索**配置，不需要改写 Agent 本身的设置。

左侧 **用量**区域可以切换今天、7 天、30 天和全部时间，查看消息数、Token、来源分布和趋势。下方的 **剩余额度**用于查看 Claude Code 和 Codex 的当前额度；可以在设置中隐藏不需要的额度卡片。

点击右上角齿轮打开设置，常用选项包括：

- **默认终端**：选择 Resume 使用的终端。
- **全局快捷键**：修改打开搜索窗口的系统快捷键，并查看应用内的 `Cmd+F` / `Ctrl+F` 搜索快捷键。
- **连接**：管理 SSH 和 WSL 环境。
- **可选来源**：启用更多 Agent 会话。
- **AI**：管理自动摘要、批量摘要和 MCP。
- **远程同步 / Skills**：配置跨设备同步。
- **外观**：切换主题、语言和 Dock 显示方式。
- **关于**：检查并安装更新。
