# ADR 0001：V1/V2 产品数据隔离

## 状态

已采用；补录当前实现的边界，不追溯或推定原始决策日期。

## 背景

稳定版与预览版并行存在。V1 使用 SQLite 和主要为同步的 store，V2 使用 PostgreSQL 和异步 store，并增加自动化能力。二者可能同时安装，预览功能的格式演进不能隐式改写稳定版的数据。

## 决策

保持独立命令、应用数据、数据库、MCP 标识和更新缓存。V2 不自动读取或导入 V1 数据。会话相关行为适用于两产品时分别实现和验证；用户原始会话来源可以相同，但各产品索引不是共享数据库。跨版本迁移若新增，必须作为显式产品能力定义格式、恢复和失败语义。

## 影响

用户可并行使用两版，预览版升级的数据影响留在自身边界内。代价是重复索引、存储和双版本维护；不能为减少代码量直接共用持久化实现。文档和发布说明必须明确适用产品。

## 考虑的替代方案

共用同一个数据库会将发布节奏、迁移和回滚耦合；首次启动自动导入会新增源数据识别、复制和恢复承诺。当前保留隔离，两项都不能作为实现细节偷偷加入。
