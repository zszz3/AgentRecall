# ADR 0011：分开会话搜索与资源搜索

状态：已采纳，适用于 V2 与配套 CLI。

## 背景

Agent 既需要查找历史处理过程，也需要读取可复用的团队文档与 Skill。两者索引、身份、排序和正文读取方式不同。桌面已拥有 PostgreSQL 和团队本地工作副本。

## 决策

会话与资源提供独立搜索、读取接口。CLI 通过 V2 现有认证回环桥接复用服务，MCP 暴露同一接口。保持默认本机范围，团队必须显式选择。检索只读取本地，不主动同步。团队引用绑定仓库和分享版本，资源正文分页返回。

## 影响与替代方案

不增加重复索引、不要求 CLI 持有数据库凭据；代价是搜索需要桌面运行。独立无桌面搜索进程可以后续单独设计，当前不启动隐式后台服务。统一 recall 排名会混淆会话和规范，因此不采用。V1 独立会话 MCP 保持原行为。
