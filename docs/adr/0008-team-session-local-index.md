# ADR 0008：团队分享复用本地会话索引

状态：已采用，当前开发分支。范围仅为 V2；V1 没有团队空间。

## 背景

共享会话通过压缩包分发。每次阅读都解码并向页面传输完整正文，导致切换页面与重启后重复等待；独立的全文阅读器也偏离本地 Session 的体验。

## 决策

压缩包只承担分发。首次导入在单个事务内调用普通 Session 写入器，写入相同的会话、原始事件、轮次、消息和工具轨迹表。团队快照表只保存来源身份和原始阅读投影，保障原始轮次身份、未知元数据及父子关系可重建。部分分享直接提供已导出的轮次结构，不将不连续片段重新推断成连续会话。

以仓库、作用域、资产 ID、摘要和投影版本确定缓存身份。内部会话与轮次主键按分享隔离。外部文件路径不在本机解析；本地副本只用于阅读，完整附件仍随包下载。

普通会话查询使用 `local_sessions` 视图，只包含未关联团队快照的记录。查询、统计、索引清理及 MCP 保持本地语义。数据库升级新增表、关联列与视图；旧会话关联列为 NULL，不重写内容。以后扩展 sessions 列或删除视图依赖列时，迁移必须同步维护该视图。

读取复用普通轮次仓库与 TurnAccordion。首屏仅取元数据和最多 50 轮摘要，正文按展开读取。事务失败与取消不发布部分结果；缓存版本变化重新导入，原分享保持不变。

## 影响与替代方案

重复阅读和重启无需重新下载正文。首次解码和索引仍有成本，单个超长 Turn 的读取限制与普通 Session 相同。快照及普通索引占用额外本地空间，尚未提供自动缓存清理。远端撤回无法抹除成员已有副本。

没有继续维护独立的团队消息表或仅在页面缓存整份 JSON；这两种方案会分别复制存储逻辑或无法跨页面和重启复用。也没有直接使用原来源会话 ID，以免覆盖用户本地数据或其他成员分享。

契约和验证入口见[团队资产规格](../spec/team-assets.md#共享会话的本地读取)。


共享会话采用与本地 Session 一致的列表与阅读分栏，可调整列表宽度。选中未下载会话只显示信息；点击下载后由应用管理队列，依次下载、解码并建立索引。列表显示等待、下载中、建立索引、可阅读或失败，支持取消和重试。关闭阅读区、切换页面不会取消任务；关闭应用或停用团队会取消未完成任务，下次需要重新点击下载，已完成副本保留。每次最多处理一条会话，避免多份大包同时占用内存。

下载与解析使用独立 Worker，Worker 独占数据库连接并在退出时关闭；取消超过五秒仍未退出则终止 Worker，未提交事务由连接关闭回滚。读取入口只返回已提交的本地快照，不再隐式下载。任务状态驻留应用生命周期，尚不支持重启续传。
