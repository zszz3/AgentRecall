# 0010：资源文件夹独立于安装路径

状态：已采用，当前开发分支。

## 背景

团队希望按用途整理资源，但 Skills、MCP、文档和配置的安装及发现方式不同。直接移动文件会影响加载和安装归属。

## 决策

版本 5 清单和快照增加 `organization` 分类元数据，按资源类型保存目录和资源 ID 归属，复用工作副本、Diff、Push、Pull 和冲突检查。每种资源的分类为独立发布项，删除分类不删除资源，安装路径保持原有契约。

版本 1–4 读取为空分类。首次分类写入升级为版本 5，旧客户端拒绝新版本，避免发布时静默丢失分类。未增加分类的旧清单仍按原有流程写入版本 4。

## 影响与替代方案

同类型分类被多人修改时需要核对后保存，不自动合并目录树。资源内容可独立发布，暂时没有对应资源的归属记录保留。只在渲染器保存分类无法共享；直接移动文件则耦合到客户端安装，因此不采用。
