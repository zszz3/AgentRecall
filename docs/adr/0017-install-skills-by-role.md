# ADR 0017：按角色筛选工作目录的 Skill

- 状态：已采用
- 关联规格：[团队资产](../spec/team-assets.md#按角色安装-skill)

## 背景

团队 Skill 增多后，所有工作目录都安装全部 Skill，会让 Agent 的可选 Skill 过多。团队角色（[ADR 0014](0014-team-agent-roles.md)）已经声明了各自需要的 Skill，可以作为目录筛选依据。

## 决策

- 筛选是成员本机的目录设置，保存在本机工作区配置 `directories[].roles`，不写入团队仓库，不同成员可以不同。
- 默认（不写字段）安装全部团队 Skill；只有选择了角色才写入字段，避免未使用该功能的配置被旧版本拒绝。
- 选择后，Pull 把未被所选角色引用的本团队 Skill 视为本目录不再需要，沿用已有的退役流程（仅限本团队管理且未被修改的副本，留备份）。
- 所选角色在团队中被删除时不报错，只是不再贡献 Skill；界面标记为已删除，由成员取消。
- 只筛选 Skill。文档、共享指令、MCP 与 Env 是目录级配置，不随角色变化。

## 影响

- 本机配置写入角色选择后，旧版本读取配置会因未知字段失败，需要升级或在新版本中取消选择。
- 角色修改 Skill 列表后，下一次 Pull 才会在筛选目录中安装或退役相应 Skill。

## 考虑的替代方案

- 把筛选写入团队仓库：会让个人工作方式影响全队，且需要 PR 审核，放弃。
- 在 Pull 时临时选择角色：每次都要重复选择，且结果不可预期，放弃。
