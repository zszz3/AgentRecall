# ADR 0006：长期记忆按目录明确启用

## 状态

已采用，补录当前目录 Memory 的身份、捕获和删除边界。

## 背景

会话索引包含大量不同项目的历史。默认把全部历史转入长期记忆会混淆项目上下文，并把用户未选择的内容交给额外的提炼流程。

## 决策

总开关不等于选择目录。用户明确管理的目录使用独立 OpenViking 用户范围，仅捕获后续事件，不因新增目录批量导入历史。路径与身份分开，目录移动可以重新关联已有数据。

停止跟踪保留数据；永久删除先处理远端数据再移除本地映射。人工编辑有独立权威控制记录，不能被后续自动提炼无条件覆盖。

## 影响

记忆范围和用户操作相对应，项目之间保持隔离。用户需要分别准备运行组件、目录和客户端 Hook；历史复用仍通过会话搜索或明确保存完成。追加、提炼和检索必须分别显示真实状态。

## 考虑的替代方案

一个全局记忆库配置更少，但容易跨项目混用。按路径字符串直接识别目录会在移动后产生重复身份。默认导入全部历史则改变了功能的授权与数据处理范围，当前不采用。
