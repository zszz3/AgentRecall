# 功能规格

这里描述当前代码的可观察行为和实现边界。规格不是待办清单，也不是发布公告；用户操作步骤仍以各版本指南为入口。

| 规格 | 范围 | 主要边界 |
| --- | --- | --- |
| [会话索引](session-indexing.md) | V1、V2 | 来源读取、增量更新、持久化、查询和失败隔离 |
| [团队资产](team-assets.md) | V2 桌面、CLI、workspace-core | 团队与目录、Pull/Push、归属、冲突和会话分享 |
| [Runtime](runtime.md) | V2 | Runtime、执行配置、Agent、驱动路由和调用生命周期 |

这三份是首批规格，不代表整个产品已完成规格覆盖。新增其他领域时，在对应改动中补充其规格和此索引。

更新规则见 [文档约定](../AGENTS.md)，重要取舍见 [架构决策](../adr/README.md)。
