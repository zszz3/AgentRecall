# 支持 Oh My Pi 会话

## 新增功能

- ✨ 可在 **设置 → 可选来源** 中开启 Oh My Pi（omp），搜索、筛选和查看本机 omp 历史会话，包括消息、工具调用、标题和用量。
- 🧩 omp 子代理的对话会归到发起它的会话下，便于沿着任务链回看。
- ▶️ 正在运行的 omp 会话会显示实时状态并触发灵动岛提醒；可一键在终端中 Resume 继续对话。
- 🔁 支持把其他 Agent 的会话迁移到 omp，也可以把 omp 会话迁移到其他 Agent。
- ☁️ omp 会话支持云端同步与恢复、本地删除，并可从 SSH 远程机器和 WSL 中采集。已有云端数据库需要重新执行一次初始化 SQL 才能上传 omp 会话。
