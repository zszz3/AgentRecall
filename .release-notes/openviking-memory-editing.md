# OpenViking 记忆编辑修复

## 新增功能

- AI 摘要与搜索现在优先支持本机 Codex，并可单独选择摘要、搜索和长期记忆提取使用的 Codex 模型与推理强度，不会修改 Codex 的全局模型配置。

- 记忆导入会先固定本次扫描结果，并将选中会话中扫描到的全部 Turn 一次提交；导入期间新产生的内容会留到后续增量同步，减少同一会话被拆成多轮远程分析的等待时间。

- 导入长期记忆时可搜索并多选具体会话，导入过程中也能继续追加其他会话；当前任务中的会话会标记为“导入中”且不可重复选择，暂停后继续导入仍会保持原来的选择范围。

- 目录记忆、AI 摘要与搜索统一使用 Provider 页面中的同一套配置；“AI 摘要与搜索”现在也可探测、选择模型并测试真实生成连接。
- 长期记忆会结合身份、灵魂、当前问题和最近对话按类别召回；对话内容按容量、空闲或会话结束自动提取，模糊续聊也能衔接上一段工作。
- 导入历史会话时会实时显示扫描、传送和记忆提取阶段，并标明当前会话及整体进度。

## Bug 修复

- 修复点击记忆详情后列表自动回到顶部的问题；连续查看不同记忆时会保留当前滚动位置。
- 修复手动记忆首次保存时报“文件不存在”的问题，并支持直接编辑身份与灵魂记忆。
- 修复记忆详情空间较小时操作按钮变形或被挤出面板的问题。
- 修复配置记忆提取推理强度后 OpenViking 服务无法启动的问题。
- 修复 Memory 页“刷新”和“管理目录”被标题栏拖拽区域拦截或被其他操作一并锁定的问题；刷新时现在会显示状态反馈。
- 修复目录记忆每次同步都重新解析全部历史会话的问题；首次导入后仅处理新增或发生变化的 Session，并可在应用重启后自动续接未完成任务。
- 修复暂停历史记忆导入后后台仍继续分析的问题；暂停现在会真正停止 OpenViking，恢复后再续接未完成任务。
- 修复暂停期间 Session 更新后旧提取任务可能占满队列、导致新任务进度长时间不动的问题。
- 修复恢复导入后等待 OpenViking 完成已有任务时长期显示“等待导入”、看起来无法继续的问题；恢复后会立即回到运行态并保持暂停控制可用。
- 修复删除目录记忆后立即重新管理同一目录时，OpenViking 用户注册表仍在清理而直接报冲突的问题；应用现在会等待清理完成并自动重试。
- 修复暂停导入、摘要 Provider 配置不完整或目录已被部分清理时无法删除目录记忆的问题；删除会等待当前导入退出并完整清理远端用户数据，最后一个目录删除后还会清空残留队列与索引，同时保留已下载的运行组件和模型。
- 修复历史记忆导入期间页面操作被长时间锁定的问题；后台导入时仍可暂停、刷新、选择其他会话或管理记忆。
- 修复应用退出或 OpenViking 暂时繁忙时 Codex 记忆 Hook 长时间等待并报超时的问题；召回失败会快速跳过，不再阻塞提问和工具调用。
- 修复 Codex 同时保留多个会话文件时 Open 状态指向旧会话、并将辅助进程误判为独立会话的问题。
