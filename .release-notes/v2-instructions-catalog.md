# 「指令」页改为找出本机所有指令文件

<!-- release-target: v2 -->

## 新增功能

- 📚 「指令」页列出 Claude Code、Codex、Gemini CLI 等 Agent 的用户级指令，有会话的项目里的 AGENTS.md、CLAUDE.md、Cursor 规则等文件，以及团队共享指令；选中即可预览，需要修改时一键用编辑器打开或在文件夹中显示。
- 🧭 侧栏更窄，「指令」页改用全宽的列表加详情布局，支持按文件、Agent 或项目搜索。
- 👥 团队共享指令回到团队空间编辑，「指令」页只读显示。
- AgentRecall 不再把个人指令写进各 Agent 的文件；早期写入的内容会保留在原文件里，需要时用编辑器删掉即可。
