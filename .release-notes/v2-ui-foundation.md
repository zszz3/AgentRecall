# 界面换用统一字体与配色，Provider 页重新设计

<!-- release-target: v2 -->

## 新增功能

- 🎨 全应用改用系统字体和一套固定的字号、字重，同一页面不再混用多种字体和大小；侧栏和页面换用更简洁的浅色、深色配色。
- 🌗 主题新增「跟随系统」并设为默认，会随系统外观在浅色和深色之间切换；原来的「暖阳」主题并入浅色。
- 🧭 侧栏按「工作区、资源、协作、自动化」重新分组。
- 🔌 Provider 页重新设计：AgentRecall 模型和 AI 摘要与搜索单独列在上方并显示当前设置，客户端服务按 Codex、Claude Code 切换，当前写入的配置、官方账号和已保存的服务列在同一张卡片里。
