# Skill 可以在自己的文件里声明评测阶段

<!-- release-target: v2 -->

## 新增功能

- SKILL.md 顶部的信息区可以加一个 `eval-stages` 列表，声明这个 Skill 自己的评测阶段：每个阶段写名字、起点类型（写入文件 / 调用工具 / 模型说到某句话）和匹配内容。为这个 Skill 新建评测套件时，声明的阶段会自动填进方案。
- 声明只在建套件的那一刻读一次。之后在方案页改阶段、删阶段、调顺序都归你自己，SKILL.md 再改动也不会回头覆盖方案里的内容。
- 声明写错会让建套件直接失败，并说清是第几个阶段、错在哪：起点类型不认识、缺名字、缺匹配内容、阶段数超过 10 个、写了不会被读取的字段，都不会被静默忽略。失败发生在写入之前，不会留下一个没有套件指向的用例集。
- 匹配内容以 `*` 开头时要加引号（YAML 把开头的 `*` 读成别名），忘了加会直接提示这一点，而不是只甩一句「不是合法 YAML」。
