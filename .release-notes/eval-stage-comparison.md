# 阶段评测：运行对比按阶段读

<!-- release-target: v2 -->

## 新增功能

- 对比两次运行时，「按维度」那块现在按阶段分组：评整次运行的维度排在最前面且不带标题，然后是方案声明的各个阶段，最后是方案已经不再声明的阶段（老运行里有分、方案后来删掉了的那个）。
- 每个阶段的标题行给出这个阶段自己的总分（基准 → 对比）和涨跌徽章。徽章用的判读带和总分是同一条——阶段本身没有单独的重复波动数据，这一点写在了区块标题的悬停说明里。
- 阶段总分由评分器算好、随运行一起存下来，报告只负责读，所以它和总分、维度分永远是同一套口径。悬停能看到这个总分是按该阶段里几条打出分的维度加权的（例如 2/3）：判不出来的那条不会把分数拉低，但会被如实报出来。
- 两次运行里有一次是在记录阶段总分之前评的，表头会多一个「阶段总分未记录」的弱提示，说明那个阶段显示的是没有差值、而不是没有变化。
