# Session 页与会话详情更紧凑

<!-- release-target: v2 -->

## 新增功能

- 🧭 Session 页标题旁直接显示会话总数和上次更新索引的时间，AI 找会话、远程会话和更新索引放在右上角；筛选条、会话行和翻页按钮更紧凑，一屏能看到更多会话。
- 🧹 「按日期清理」和「清理残留子对话」收进搜索框旁的「更多」菜单，批量操作栏只在开始多选后出现。
- 📄 会话详情只保留 Resume、终端、打开文件夹和 AI 摘要几个常用按钮，添加标签、迁移、复制和导出、删除等收进「更多」菜单，可以用方向键选择、Esc 关闭。
- 🗂️ 会话详情里的对话轮次和子 Agent 会话改用更轻的列表样式，状态、工具调用次数、耗时和 Token 用量显示为一行文字。
