# Skill 体验升级

## 新增功能

- 应用自带 5 个官方内置 Skill（头脑风暴、系统化调试、测试驱动开发、完工验证、Grill 追问），打开「本 App Skill」即可使用，无需手动导入；内置 Skill 标记为"内置"来源、不能删除，下次启动自动恢复。
- 管理安装新增 Pi 作为可安装的 Agent，本地 Skill 页也会扫描并展示 Pi 已有的 Skill。

## Bug 修复

- 修复本地 Skill 列表重复显示同名 Skill（同一 Skill 在多个 Agent 目录里各出现一次）的问题，现在同名 Skill 只显示一份。
- 修复「管理安装」中路径被同名 Skill 占用时无法操作的问题，现在可以选择覆盖安装。
