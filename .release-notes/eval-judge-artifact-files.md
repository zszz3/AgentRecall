# 评分器现在能读到一次运行改了哪些文件

<!-- release-target: v2 -->

## Bug 修复

- 评测一次新跑出来的结果时，「脚本评判」此前拿不到这次运行改动的文件清单：清单是在全部评分结束、结果落库时才补上的，所以同一份产物，评分器读到的和你在运行页读到的是两回事。现在文件清单在评分开始之前就补进产物，两边读到的是同一份。
- 运行页的步骤里因此多出一个「产物文件」步骤，写明有没有观测到文件改动、观测到几个、关联到哪个会话。索引迟迟没跟上或者轨迹读不出来时，这一步会如实记下原因，并把答案原样交给后面的评分器——看不到文件只是少一份证据，不会连带丢掉整个用例的评分。
