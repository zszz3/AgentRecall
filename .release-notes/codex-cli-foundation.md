# 独立 CLI 源码预览
<!-- release-target: v2 -->

## 新增功能

- 可从源码安装独立的 AgentRecall CLI，无需启动桌面应用即可管理多个项目的团队归属；团队默认关闭，可随时开启或停用。
- 可手动拉取团队 Skill，预览后选择版本安装到当前项目的 Codex 或 Claude Code；更新前可查看差异，更新和卸载会保留备份，并可主动回滚。已有个人内容和本地修改不会被自动覆盖。Session 分享尚未开放。
- 可将多个团队 Skill 组成工作配置，预览整组安装状态和冲突后选择安装；相同内容直接复用，安装失败时保留已有内容并提供恢复提示。
