# 团队资产与工作配置
<!-- release-target: v2 -->

## 新增功能

- V2 新增可选的团队空间，直接浏览共享会话、Skills 与文档；可分别为多个工作目录选择客户端并启用或停用，本地页面保持原有布局。
- 可从会话右键菜单预览并主动分享完整快照到私有团队仓库，团队成员可阅读和下载，作者或管理员可撤回；不会自动上传会话。
- 团队文档支持预览开发约定和项目说明并应用到本地；已有不同内容会保留，避免覆盖个人修改。
- 团队 Skill 和工作配置可预览后按项目安装；工作配置支持查看整组差异、按版本更新和整组卸载，共用 Skill 与原有独立安装会保留。
- 可从源码安装独立的 AgentRecall CLI，通过仓库地址初始化团队资产，重复初始化保留已有内容；无需启动桌面即可管理 Skill 和工作配置。

## Bug 修复

- 团队页面精简重复操作，统一按钮、列表与目录开关样式，并改善窄窗口下的布局。

- 选择本地工作目录后可查看已有 Skills 和 Markdown 文档，明确区分本地内容与团队仓库资产，不会自动上传文件。

- 移除多人 Chat 页面、工作台入口及聊天任务执行；已有聊天数据和关联的 Session 保留，历史会话仍可查看。
