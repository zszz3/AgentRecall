# 团队资产与工作配置
<!-- release-target: v2 -->

## 新增功能

- V2 新增默认关闭的团队工作区，可管理多个 GitHub 资产仓库及项目绑定，并与独立 CLI 共用配置。
- 可预览团队 Skill 和工作配置，选择 Codex 或 Claude Code 按项目安装；工作配置支持查看整组差异、按版本更新和整组卸载。
- 共用 Skill 和原有独立安装会保留，本地修改不会被强制覆盖；操作失败时提供备份与恢复提示。
- 可从源码安装独立的 AgentRecall CLI，无需启动桌面即可使用团队资产和单 Skill 版本管理；完整 Session 分享尚未开放。
