# 团队资产与工作配置
<!-- release-target: v2 -->

## 新增功能

- V2 服务商页支持分别保存、编辑和启用多套 Codex、Claude Code 配置；摘要与搜索可复用已保存的兼容 API 服务。

- 团队共享会话支持搜索 Turn 内容并定位原轮次，可选择搜索工具输出；Pull 后列表、搜索和阅读均可离线使用。

- V2 新增可选的团队空间，直接浏览共享会话、Skills、文档与配置；可分别为多个工作目录选择客户端并启用或停用，本地页面保持原有布局。
- 可从会话右键菜单分享完整快照，也可在轮次上右键进入多选，仅分享所选轮次的消息、工具记录和附件；支持公开和私有团队仓库，上传前可预览并了解可见范围，可阅读和下载，作者或管理员可撤回，不会自动上传会话。
- 团队页提供 Pull 拉取与 Push 推送：可逐项勾选 Skill、文档、配置、完整会话和会话轮次，查看当前 Diff 后上传；成功项移出清单，失败项保留重试。
- 一次同步即可安装或更新已启用工作目录中的团队 Skills、文档与配置，保留旧版本备份和本地修改，分别展示每个目录的完成、冲突、失败与取消结果。
- Skills 和文档页集中浏览团队资源，无需逐项安装；连接方式在团队设置中保存，工作目录按客户端分别启用。
- 可从源码安装独立的 AgentRecall CLI，通过仓库地址初始化团队资产，重复初始化保留已有内容；无需启动桌面即可管理 Skill 和工作配置。

- 共享指令、MCP 工具连接和公共环境变量各有独立页面，可在应用内新增、编辑、预览并发布到团队，按工作目录选择的客户端同步；保留个人配置与本地修改，密钥由成员在本机提供。

## Bug 修复

- 共享会话可导出为新的本地 Agent Session，完整分享和 Turn 片段均可继续 Resume；选择工作目录后即可在普通会话列表中使用。

- 恢复共享会话的 MD 和 JSON 导出入口，可离线导出完整分享或 Turn 片段的对话与工具记录。

- 共享会话沿用普通会话的搜索输入与最近搜索，一次查找标题、分享者和对话内容，按 Enter 搜索并定位命中轮次。

- 共享空间统一显示本地团队资源，未上传的会话、Skills、文档和配置也可直接查看；Push 按本地差异上传，Pull 保留待上传内容，重启后可继续处理。
- 上传会话后立即加入本地共享列表并可搜索，无需额外 Pull；本地整理失败时保留上传成功状态，避免重复上传。
- 共享会话搜索使用紧凑的筛选按钮，减轻阅读区高亮边框，窄窗口下控件保持清晰易用。
- 加快共享会话的阅读：先读取正文，将原文件和附件留到下载时获取；复用重复内容及当前页面已读会话，减少重复等待。
- 在会话或轮次上点击上传后直接打开上传窗口，可选择团队并直接上传，无需跳转团队页面或先查看 Diff；失败原因和完成结果留在窗口中显示。
- 共享会话无损压缩重复图片、长工具输出与附件，重复上传可复用已上传内容；不同成员保留独立分享记录和撤回权限。
- 团队页的 Pull 和 Push 使用紧凑、统一的工具栏按钮，拉取时清楚显示进度并可取消。
- 加快 Push 清单中的 Diff 查看与条目切换，读取时仍可勾选和操作；已查看结果直接复用，推送前仍核对远端变更。
- 窄窗口下左侧导航保持紧凑，团队资源入口自动换行，避免挤压内容区。

- 团队空间的文档点击后直接在右侧打开，窄窗口使用覆盖式详情；关闭后保留列表位置，快速切换不会显示上一份文档的内容。

- V2 统一浅色与深色界面的页面标题、筛选和表单样式，减轻灰色背景，并用柔和强调色突出主操作与当前选择；侧栏采用更紧凑的分组文字导航，窄窗口自动收起为图标，工作台卡片换行不再与列表重叠。


- 移除多人 Chat 页面、工作台入口及聊天任务执行；已有聊天数据和关联的 Session 保留，历史会话仍可查看。

- 工作台顶部的用量、模型额度和 Token 趋势卡片更紧凑，减少留白，让最近会话更早显示。

- 首页统一展示全部来源的会话与用量，移除普通和 AgentRecall 的来源选择，保留时间范围筛选。

- 首页移除输入、缓存读取、缓存写入、输出、推理明细和缓存率，简化用量卡片。

- 加快较长 Codex 纯文本会话的新消息更新，减少后台索引带来的等待。

- V2 在后台处理历史会话索引，减少打开应用或更新长会话时界面短暂停顿。

- 团队共享会话首次阅读后保存在本机，再次打开无需重新下载；完整会话和片段统一按轮次阅读，长会话支持分页和按需展开。

- 共享会话使用与本地会话一致的列表和阅读分栏；下载在后台继续，可查看状态、取消或重试，切换会话不会中断下载。
- 团队空间采用紧凑顶栏，合并多层标题，缩减同步栏高度并移除冗余说明文字，资源标签栏更紧凑；共享会话列表不再固定高度，随窗口自动铺满；修正样式选择器范围，确保会话列表交互样式在生产环境中正确生效。

- 返回共享会话时先显示已读列表，后台更新远端变化；已读会话和轮次摘要直接复用，减少切换时的空白与等待。

- 分享会话时同时上传来源 Agent，无需下载正文即可在列表中区分 Codex、Claude Code 等来源；已有本地副本也可显示来源。
