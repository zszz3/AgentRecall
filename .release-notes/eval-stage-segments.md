# 评测可以按阶段看一次运行

<!-- release-target: v2 -->

## 新增功能

- 方案页新增「阶段」区，可以声明一次运行分成哪几个阶段，以及每个阶段从「首次写入哪个文件」开始。比如一个写周报的 Skill 可以声明「数据采集」和「周报撰写」两段，后者从报告文件被写出来那一刻开始。
- 阶段可以增删、改名、上下移动。顺序就是切分方式：每个阶段只在它前一个阶段开始之后才搜索，所以顺序调错了切分也就错了。
- 运行结果里每个阶段单独一行，写明它是被哪个文件开启的、截至那里这次运行累计改了多少个文件；另有一行写明一共读到多少处文件改动。
- 匹配不到的阶段显示为「无法判定」，并写明「没有文件命中这个阶段的匹配模式」以及它在找什么。识别不到只是少一份观测，不计入评分也不会判成不通过；它后面的阶段显示为「未执行」，因为切分在那里就停住了。
- 评测产物文件夹时背后没有会话，也就没有可切的运行，声明的阶段会明确报成「已跳过」，不会静默少几行。
