# Eval：Skill 摩擦诊断 Findings 与双向入口

<!-- release-target: v2 -->

## 新增功能

- 🔍 Eval 页选中 Skill 后，实况报告上方新增 Findings 段：基于真实触发数据自动产出四类诊断结论（已装未用、工具反复失败、触发轮次成本偏高、触发轮次频繁出错），每条结论带严重度、证据强度、样本量和可展开的证据，并给出排查方向——不做因果断言，样本不足时保持沉默。
- 🔗 Skills 页的技能列表现在显示 Findings 数量徽标，点击直接跳转到 Eval 页对应 Skill 的诊断详情；Eval 关闭时不渲染任何徽标。
- 所有结论标注证据强度与样本量，零 Finding 时明示"未发现"不等于"没问题"。
