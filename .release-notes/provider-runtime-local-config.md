# 本地 Provider 配置与 Runtime 离开提示修复

## Bug 修复

- Provider 现在会以 Codex 和 Claude Code 当前实际使用的本机配置与 API Key 为准；应用中残留的旧 Provider 信息和已删除的配置目录不再覆盖本地配置。
- 摘要 Provider 的 Codex 测试连接现在会通过本机 Codex CLI 验证，与实际生成摘要时使用的连接方式保持一致。
- 会话文件时间较大时，AI 摘要不再因时间戳超出整数范围而失败。
- Runtime 不再把未发生变化的配置误判为未保存；确有修改时，离开页面可以选择保存、不保存或取消。
- 从会话恢复打开终端时，超长标题截断后不再残留尾部空格。
