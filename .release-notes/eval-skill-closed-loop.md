# Eval：Skill 回归评测闭环——自定义用例、一键重跑、版本对比

<!-- release-target: v2 -->

## 新增功能

- 🧪 Eval 页的 Skill 回归评测现在是完整闭环：为任何 Skill 定义测试用例（输入 + 可选期望输出），内置 LLM 评审开箱即用，无需配置评分器和评审运行时，一键创建并运行。
- ▶️ 运行不再阻塞界面：启动后立即显示逐用例进度（如"运行中 1/3"），可随时取消；方案支持随时编辑（改用例、换执行 Agent）和删除。
- 🔍 每次运行的证据完整可见：逐用例展开输入、实际输出、每个评分器的分数与中文评审理由、未达标项清单，直接指导你修改 Skill。
- ⚖️ 改动 Skill 后一键验证"变好还是变坏"：运行历史里任选两次运行对比，逐用例分数变化与双方输出并排展示，并标注两次运行对应的 Skill 版本。
- 🌐 评审结论与诊断文案支持中文：内置评审以中文输出评审理由和未达标项。
