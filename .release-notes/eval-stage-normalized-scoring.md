# 阶段评测：按阶段计分与分组查看

<!-- release-target: v2 -->

## 新增功能

- 评测方案里的每个阶段现在可以单独设权重。评同一个阶段的维度平分这份权重，所以在某个阶段上多挂几条检查，不会让这个阶段在总分里更有话语权。
- 方案页和运行页的维度卡片按阶段分组显示，评整次运行的维度排在最前面。卡片上的权重是这个维度实际占到的份额，鼠标悬停能看到方案里声明的原值。
- 改动阶段的顺序或匹配模式之后再对比两次运行，会提示「评分标准已变更」；只改阶段名字不会提示，因为测的还是同一件事。
- 对比两次运行时，如果汇总分数所用的口径变过，会单独提示「计分口径已变更」，并说明涨跌可能来自算法本身而不是被测对象；早于这次改动的运行提示「计分口径未记录」，不会假称两边可比。

## Bug 修复

- 修复编辑或运行「技术教程写作与审校」的评测套件时，方案页上改过的权重和阈值被静默重置回默认值的问题；这次重置还会让运行对比误报「评分标准已变更」。默认值现在只在建套件时生效。
- 清掉存量「技术教程写作与审校」套件里那个要求每项检查都判出结果的覆盖率下限，它会让任何一次有一项判不出来的运行都通不过。
