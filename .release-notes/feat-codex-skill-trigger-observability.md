# Codex Skill 使用情况现在看得见了

## 新增功能

- Codex 里用过的 Skill 终于会出现在 Eval 页里。以前无论你在 Codex 中调用过多少次 Skill，页面都显示"从未使用"；现在每一次调用都会被记录，并关联到它所属的那次会话。
- 每条 Codex Skill 触发还会带上"当时用的是哪个版本"，历史会话里的调用也能一并追溯，方便对比改版前后的表现。
- 被 Codex 归档的旧会话里的 Skill 调用不再丢失，归档之后依然能正常查看和关联。

## Bug 修复

- 修复无法判断"这个 Skill 到底是没用过，还是我们看不到"的问题：只有确实读不到使用记录的工具才会标为"观测不到"，不再把真实用过的 Skill 误报成"从未使用"。
- 调用失败的 Skill（例如名字写错、Skill 不存在）不再被统计成一次使用，使用次数更贴近真实情况。
- 修正设置页对 Claude 使用统计 Hook 的说明：Skill 触发本来就能从会话记录中探测并关联，Hook 的作用是额外记录触发当时的 Skill 版本。
