# AgentRecall 1.0 核心体验

## 新增功能

- 提供专注于搜索、筛选、查看和恢复本机 Claude Code 与 Codex 会话的精简桌面界面，并支持收藏和重命名。
- 会话详情支持安全的 GitHub Flavored Markdown、长内容折叠、虚拟化时间线，以及按需加载更早消息。
- 设置中可控制原生更新检查，并在发现新版本后显式下载、安装、重试或查看故障帮助。
- 诊断页面提供脱敏的本地健康报告，并可在逐项预览、再次确认和自动备份后清理 AgentRecall 自有遗留集成。

## Bug 修复

- 启动或通过 npm 安装时不再自动修改 Claude Code、Codex 或 Shell 配置，也不会自动启用高级集成。
- 修复分页结果数量不准确、已消失会话恢复时误报成功，以及 Windows 特殊字符项目路径无法可靠恢复的问题。
- Markdown 默认阻止联网图片、文件链接和网络共享图片，避免仅查看历史会话时意外访问外部资源。
