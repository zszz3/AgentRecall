# 修复 Windows 平台多项兼容性与交互问题
<!-- release-target: both -->

## Bug 修复

- 修复 Windows 下后台任务（远程会话监听、WSL 环境检测、智能记忆服务与 MCP 配置探测）执行时闪现黑色命令行窗口的问题，并为智能记忆服务默认启用 UTF-8 编码，避免中文系统环境下出现乱码或编码错误。
- 修复 Windows 下 Claude Desktop 与 Cursor 会话、工作区路径及附件目录的识别与解析问题，并统一项目路径的盘符大小写，避免同一项目因盘符大小写差异被拆分为多条重复记录。
- 提升 V2 本地数据服务在 Windows 上的启动稳定性：当原端口被系统保留或其它程序占用时自动切换可用端口恢复启动，兼容中文系统区域初始化，并支持在 Windows ARM64 设备上运行。
- 修复 Windows 下活跃会话状态检测与窗口聚焦定位能力，准确识别终端及 Codex CLI 的运行状态，并在使用 Windows Terminal 时定位切回对应终端窗口。
- 改进 Windows 下团队 Git 同步、外部裁判脚本与命令行工具探测：保留用户在 Git 中自定义的 SSH 配置，修复外部裁判脚本的启动兼容性与超时进程树清理，并支持从全局包管理器生成的启动脚本中识别已安装的 V2 命令行工具。
- 优化 V2 桌面端在 Windows 与 Linux 上的界面与键盘交互：将页面头部窗口拖拽区域限制为仅 macOS 生效以恢复弹窗点击与文本选中，在无菜单栏模式下补全缩放、设置、刷新、全屏与开发者工具快捷键，并修复 MCP 参数输入框无法键入空格及拆分带空格引号路径的问题。
