# 阶段评测：阶段可以从工具调用或模型说的话开始

<!-- release-target: v2 -->

## 新增功能

- 评测方案里的阶段不再只能从「首次写入某个文件」开始，还可以选「首次调用某个工具」或「模型首次说到某句话」。
- 匹配框的提示跟着起点类型变：文件起点填文件名（可用 `*` 通配），工具起点填工具名，说话起点填一段文字。后两种按字面比较，不当正则解析，所以写一句普通的话不会触发通配符数量限制。
- 运行报告里会写清每个阶段是从什么开始的——哪个文件、哪次工具调用，还是模型说的哪句话（太长会截断）；没识别到的阶段也会写明它在找什么。
- 阶段切分那一行现在同时报出读到的文件改动数和工具调用数。
