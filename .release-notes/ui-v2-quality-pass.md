# 桌面界面层级与窄窗口布局改善
<!-- release-target: v2 -->

## Bug 修复

- 窄窗口或放大界面时，MCP 工具源长列表保持可滚动，避免底部条目被裁切。

- 统一调柔分割线的悬停与键盘聚焦高亮，减少视觉干扰。

- 会话范围的标题、分组和筛选项层级更清楚；展开和折叠支持平滑过渡，并尊重系统的减少动态效果设置。
- 长分支标签保持单行省略，悬停可查看完整内容，不再挤掉会话标题；窄窗口中的搜索、筛选和操作按钮按组排列。
- 调整工作台卡片比例并避免图例重叠，四项用量指标等宽居中排列，与顶部筛选保留清晰间距，保留自定义工作入口顺序。
- 用量数字随卡片宽度调整字号，改善缓存率截断；模型额度以更清晰的图标、文字和紧凑分行展示，趋势图日期与底部汇总留白更充分。
- 工作台刷新提示不再改变卡片高度，也不再显示整行背景；用量数字和 Token 构成增加留白与分隔，趋势图换行后仍保留充足高度。
- Token 趋势记住选定的时间范围，切换页面或重新打开应用后不再恢复为 7 天。
- 页面标题、描述和间距保持一致；工作台辅助文字更易读，刷新反馈保留内外留白，长错误信息可换行显示，设置窗口圆角更自然。
- Runtime、Workflow 和 Skills 主分栏支持拖动、键盘调整和宽度记忆；窄窗口自动切换布局，Runtime 状态信息与操作按钮不再互相挤压。
- Provider 和 Runtime 详情采用居中的适度最大宽度；Provider 预设卡片增加宽度和文字内边距，随窗口自动调整列数，长配置路径可查看完整内容。

- 主导航按用途分组，在更宽的窗口显示完整分组名称，默认窗口为主内容保留更多空间。
- Token 趋势支持方向键切换日期，键盘导航不再逐个经过所有日期；点击图表空白处也能选择附近日期。

## 新增功能

- 工作台 Token 趋势支持近 7、30 和 90 天，可查看每日明细并跳转到对应日期的会话。

- Session、Chat 和 MCP 的左侧列表支持拖动调整宽度，并记住各页面的选择。
- View 菜单显示当前界面缩放百分比，随放大、缩小、重置及字体大小设置同步更新。
