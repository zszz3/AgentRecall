# 运行对比会区分真的回归和本来的波动

<!-- release-target: v2 -->

## 新增功能

- 运行对比新增「按维度」一栏，把两次运行的每个维度按名字配对，列出各自的分数和涨跌。此前只有一个总平均分，一个维度回归、另一个维度改进会被平均成「基本没变」，看不出到底是哪条标准动了。某个维度只在其中一次运行里存在、或其中一次没能得出结论，都会单独标出来，不会消失也不会显示成 0。
- 涨跌不再一律按「负数就是回归」上色，改用这个用例自己在多次重复之间的分差来判读：同一个用例一次 1.00、一次 0.70 时，0.20 的下跌本来就在它的抖动范围内，不该报成回归。超出重复波动范围才算改进或回归，范围内按波动处理，停在涨跌上会写明用的是哪条范围。
- 对比视图会说明自己建立在多少证据上：多少个用例两次都跑了、多少个用例跑了不止一次（波动范围就来自这些重复）、哪一次运行有多少用例没能评分、以及只在单边出现的用例。每个维度也会标明自己的平均分基于多少个用例。
- 两次运行都没有把同一个用例评分过两次以上时，视图会直说缺少可参照的重复波动、分不清是改动带来的还是本来就有的抖动，而不是自己编一个默认阈值来判。

## Bug 修复

- 对比视图里单个用例的分数原先是把该用例各项评分器的分数直接平摊，而顶部的总平均分用的是按维度加权后的分，两者单位不同：单个用例的涨跌和总涨跌对不上，也和运行页显示的同一个用例的分数不一致。现在统一用加权后的分。
- 一个用例两次都跑了、但其中一次没能评分时，原先被标成「未在对比运行中重跑」，而它其实跑了。现在标为「未评分」，并在停留时给出记录下来的原因。
