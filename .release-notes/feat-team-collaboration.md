# 团队协作：角色、模板、成果与审核

<!-- release-target: v2 -->

## 新增功能

- 团队空间新增「Agent 角色」：把调好的 Agent 指令、运行时、模型系列以及配套的团队 Skill 与 MCP 发布给团队，成员可一键启用到本机并选择自己的渠道和模型；渠道和密钥只保留在本机。
- 团队 MCP、公共 Env、Workflow 模板和运行成果在保存和发布前会拦截疑似明文密钥，提示改为读取本机环境变量。
- 团队空间新增「Workflow 模板」：可以把用团队角色搭好的个人 Workflow 发布给团队，成员一键用自己启用的角色生成个人副本；第一次运行前会展示其中的脚本和权限，确认后才执行。
- 团队空间新增「运行成果」：可以把完成的 Workflow 运行一键生成成果记录，或手动记录结论，并关联已上传的共享会话作为完整对话出处。
- 「Agent 角色」页新增 Skill 角色矩阵；工作目录可以只安装所选角色用到的团队 Skill，取消选择即恢复安装全部。
- Pull 团队资源前，会先列出带脚本的 Skill 和 MCP 服务的脚本文件、启动命令或连接地址，逐项选择信任或跳过后才写入工作目录；内容更新后会再次询问。
- 团队空间新增「成员与动态」：查看最近修改过团队仓库的成员和每次改动的资源；在 App 中发布时会署上你自己的 Git 姓名和邮箱。
- 团队空间新增「审核规则」：可为 MCP、Env、Skill、Agent 角色等资源指定 GitHub 审核人并生成 CODEOWNERS；推送受保护的资源时提交到单独的审核分支，并提供「打开 Pull Request」入口。
- 团队 Skills 页可以把单个或全部团队 Skill 导出为 ZIP，解压后保留脚本的可执行权限。
