# Eval：Skill 实况报告

<!-- release-target: v2 -->

## 新增功能

- 📊 Eval 页的 Skill 列表升级为体检总表：每个 Skill 显示触发次数、近 7 天趋势和最近触发时间，已安装但从未使用的 Skill 会被直接标出，帮你发现装了却吃灰的技能。
- 选中 Skill 可查看实况报告：触发所在轮次的 token 消耗、耗时、出错占比（与全库中位数对照），以及按 Skill 内容版本切分的触发分布，改完 Skill 后能看出新版本的真实使用情况。
- 所有数字都标注证据强度和样本量，样本不足时如实提示；未安装统计 Hook 时会明确显示"观测不到"，不会把观测盲区说成"没用过"。
