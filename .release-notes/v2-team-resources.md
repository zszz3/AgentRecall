# 团队的指令、Skill 和 MCP 移到对应页面

<!-- release-target: v2 -->

## 新增功能

- 👥 团队共享的指令、Skill 和 MCP 现在直接在「指令」「Skills」「MCP」页查看和编辑：指令页下方是团队指令，Skills 页新增「团队 Skill」，MCP 页右上角可切换到团队。修改先保存在本机，页面会提示还有几项没有 Push。
- 📥 团队内容可以复制给自己：团队指令「加入个人指令」，团队 Skill「加入 Skill 库」，团队 MCP「加为工具源」（默认关闭，测试后开启）。复制后是独立副本，不随团队版本变化。
- 🧭 团队空间只保留共享会话、Agent 角色、运行成果、文档、Env 等内容，顶部提供前往指令、Skills、MCP 页的入口。
- 🧹 Agent 角色不再提供「启用到本机」，角色只用来说明团队分工和按角色安装 Skill；以前启用过的本机 Agent 仍保留在 Runtime 页。
